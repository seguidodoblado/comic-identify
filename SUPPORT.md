# Support

Consulta primero el `README.md` y la documentación disponible
en el repositorio.

## Problemas

Si encuentras un error reproducible, utiliza el sistema de
issues del repositorio proporcionando toda la información
relevante.

Para preguntas o propuestas generales, utiliza el canal de
comunicación indicado por los mantenedores del proyecto.
