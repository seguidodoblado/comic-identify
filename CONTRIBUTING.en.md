# Contributing

Thank you for your interest in contributing to this project.

## Development

Consult the section [Development environment](https://github.com/seguidodoblado/comic-identify/wiki/en-01-4-installation-and-setup#development-environment)
from the wiki to prepare the environment, and
[Checks (to contribute)](https://github.com/seguidodoblado/comic-identify/wiki/en-01-4-installation-and-setup#checks-for-contributing)
to know what should happen before opening a pull request.

## Changes

Before making major changes, open an issue to
describe the proposal and facilitate its discussion.

## Pull Requests

Contributions must include appropriate evidence
when applicable.

Changes must maintain quality and conventions
established for the project.
