# Security

## 🇪🇸 Español

## Notificación de vulnerabilidades

Si encuentras una posible vulnerabilidad de seguridad, evita
publicar los detalles en una issue pública.

Utiliza el mecanismo privado de contacto disponible en el
repositorio para comunicar el problema a los mantenedores.

## Información recomendada

Cuando sea posible, incluye:

- Descripción del problema.
- Pasos para reproducirlo.
- Impacto potencial.
- Versión afectada.
- Cualquier información adicional que pueda ayudar a
  investigar el problema.

Gracias por ayudar a mantener este proyecto seguro.

## 🇺🇸 English

## Vulnerability notification

If you find a possible security vulnerability, avoid
post the details in a public issue.

Use the private contact mechanism available in the
repository to communicate the problem to maintainers.

## Recommended information

When possible, include:

- Description of the problem.
- Steps to reproduce it.
- Potential impact.
- Affected version.
- Any additional information that may help
investigate the problem.

Thank you for helping keep this project safe.
