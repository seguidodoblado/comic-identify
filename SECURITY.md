# Security

## Notificación de vulnerabilidades

Si encuentras una posible vulnerabilidad de seguridad, evita
publicar los detalles en una issue pública.

Utiliza el mecanismo privado de contacto disponible en el
repositorio para comunicar el problema a los mantenedores.

## Información recomendada

Cuando sea posible, incluye:

- Descripción del problema.
- Pasos para reproducirlo.
- Impacto potencial.
- Versión afectada.
- Cualquier información adicional que pueda ayudar a
  investigar el problema.

Gracias por ayudar a mantener este proyecto seguro.
