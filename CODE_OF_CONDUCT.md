# Code of Conduct

## 🇪🇸 Español

## Nuestro compromiso

Esperamos que todas las personas que participen en este
proyecto mantengan un entorno respetuoso, constructivo y
colaborativo.

## Comportamiento esperado

Se espera una comunicación respetuosa y profesional.

No se tolerarán comportamientos de acoso, discriminación,
insultos o ataques personales.

## Aplicación

Los mantenedores del proyecto podrán tomar las medidas que
consideren apropiadas ante comportamientos inaceptables.
